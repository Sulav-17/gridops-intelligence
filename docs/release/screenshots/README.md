# Screenshot Capture Guide

Do not add fabricated screenshots. Capture these from a verified local or deployed dashboard, preserving the fixture-backed label when fallback data is in use.

Required captures:

1. Overview
2. Forecasts
3. Alerts list
4. Alert detail
5. Data quality
6. Scenario input
7. Scenario result with interval comparison
8. Briefing
9. Model performance
10. System status
11. Mobile view

Suggested lightweight process: run the backend and frontend using the deployment guide, use a browser’s built-in responsive device toolbar for the mobile capture, and save optimized PNG files in this directory with descriptive names such as `overview.png` and `mobile-overview.png`. No browser-automation framework is added solely for screenshots.
