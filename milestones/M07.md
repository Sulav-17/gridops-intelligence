Product Positioning

GridOps Intelligence should be positioned as:

A production style energy data engineering, forecasting, and MLOps platform for Ontario electricity demand operations.

It should demonstrate that the system can:

ingest and preserve source evidence
validate source health
generate day ahead demand forecasts
compare models and baselines
quantify uncertainty
detect attention conditions
run controlled planning scenarios
generate deterministic operational briefings
explain limitations honestly

It must not claim to replace IESO, control the grid, predict emergencies, or provide trading advice.

API Client Requirements

The dashboard should use a typed API client or equivalent clean data access layer.

The API client should handle:

base URL configuration
typed response models where practical
safe error states
loading states
demo mode fallback where required

Do not hardcode local only URLs in production facing code.

Demo Mode Requirements

M07 must support a safe public demo mode.

Demo mode should:

avoid requiring visitors to mutate production data
avoid exposing private credentials
use seeded demo data or read only backend data
bound scenario input values
clearly label demo limitations
prevent unsafe or expensive operations
keep public experience stable even if live ingestion is unavailable

If full live deployment is not available, provide a documented demo mode using seeded or fixture backed data.

Recommended Codex Breakdown

Review existing backend APIs, identify dashboard data needs, add small integration endpoints or serializers only if necessary, and document API contracts.

M07-C02 — Frontend Foundation and Dashboard Shell

Create or refine frontend structure, layout, navigation, API client, loading states, error states, and demo mode data path.

M07-C03 — Forecast, Quality, and Model Performance Screens

Implement forecast views, quality/source health views, and model performance views using verified backend or demo data.

M07-C04 — Alerts, Scenarios, and Briefing Screens

Implement alert views, scenario controls/results, and deterministic briefing views with evidence and limitations.

M07-C05 — Deployment, Demo Mode, Documentation, and Release

Implement deployment configuration, demo mode hardening, documentation, case study, demo script, release checklist, verification report, handoff, and v1.0.0 readiness.
